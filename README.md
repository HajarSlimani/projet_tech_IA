# Emotion-Based Recommendation System (FeelMate)
## Realisé par : Hajar Slimani et Khadija Maaroufi

## Description

Ce projet propose un système intelligent capable de détecter l’émotion de l’utilisateur à partir de **texte**, d’images, ou de la **webcam**.
Selon l’émotion détectée, l’application recommande automatiquement du **contenu personnalisé** :
films, playlists musicales, activités et idées repas.

L’objectif est d’accompagner et améliorer l’état émotionnel de l’utilisateur de manière positive.

## Fonctionnalités principales

* Détection d’émotion (texte + vision)
* Classification en 6 émotions : **Happy, Sad, Angry, Anxious, Relaxed, Bored**
* Recommandation multi-sources :

  * API TMDB (films)
  * API Spotify (playlists)
  * Base locale (activités et repas)
